# UI Module

This module contains all user interface components and visual resources for ZenRunner.

## Responsibilities

- **QML Files**: Declarative UI components and layouts
- **GLSL Shaders**: Custom visual effects for glassmorphism design
- **UI JavaScript**: Animation logic and UI-specific behavior

## Key Components (Planned)

- `Main.qml`: Application entry point and window configuration
- `Dashboard.qml`: Project overview and quick actions
- `ProjectView.qml`: Detailed project view with script buttons
- `LogConsole.qml`: Terminal-like log display with ANSI color support
- `WorkspaceManager.qml`: Workspace creation and management interface
- Shaders for blur, transparency, and glassmorphism effects

## Design System

- Glassmorphism aesthetic with native material support
- 60 FPS rendering target using Qt Quick Scene Graph
- Responsive layout adapting to window size
- Dark theme optimized for developer workflows
